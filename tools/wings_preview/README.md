# 展翼主题素材生成器

以中线铰链为轴的抽象矢量翅膀动态壁纸素材生成与校验工具。

- 折叠态（t=0）：右翅收折在左翅之下（左盖右）。
- 展开过程：右翅绕铰链"翻页式"展开（x 方向按 cos(θ) 投影压缩模拟 3D），
  t 与铰链角度 1:1 线性映射（无缓动），θ>90° 时不绘制右翅（避免回摆假动作）。
- 展开态（t=1）：双翅完全展开。

## 用法

```bash
python generate_wings.py   # 生成全部变体到 output/
python e2e_check.py        # 端到端校验（含 assets 同步检查）
```

依赖：Python 3 + Pillow + ffmpeg（PATH 可用）。

## 变体与分辨率

| 变体 | 外屏 | 内屏 | 备注 |
| --- | --- | --- | --- |
| 默认 | 1080×2400（竖） | 1812×2176（竖） | |
| `_wide` | 1168×1712（竖） | 2364×1672（横） | 外屏竖屏、内屏横屏的宽折机型 |

注意：系统 `wm size` 可能按横向报告分辨率（如外屏报 1712×1168），
素材必须按壁纸 surface 的实际方向生成，否则会被 surface 裁剪。

## 外屏壁纸生成策略（outer_mode）

- **默认变体**：渲染 t=0 折叠态场景的内屏左半幅（与内屏同一比例尺，
  铰链贴右边缘，左盖右），cover 铺满裁剪。若半幅宽高比与外屏差异 >15%，
  改为在外屏设计空间直接渲染（ref_min=内屏短边），避免裁掉翅尖。
- **`_wide` 变体（inner_right_half，最终确认方案）**：
  取 t=1 展开态内屏图的**右半边**（铰链在左边缘、含完整右翅与翼根光晕），
  cover 铺满放大到外屏分辨率 1168×1712。
  两者宽高比（1182×1672 ≈ 0.707 vs 1168×1712 ≈ 0.682）接近，仅裁约 21px。

## 输出（output/，{s} 为后缀）

| 文件 | 用途 |
| --- | --- |
| `outer{s}.png` | 外屏壁纸 → `app/src/main/assets/themes/wings{s}/` |
| `inner{s}.png` | 内屏壁纸 → 同上 |
| `wings{s}.mp4` | 45 帧合成的预览视频，亦作 App 内置展开动画素材 |
| `frames{s}/` | 45 帧 JPEG 序列（30fps 合成源） |
| `contact_sheet{s}.png` | 全部帧速览 |

改素材后的完整流程：重新生成 → 拷贝进 `app/src/main/assets/themes/` →
`python e2e_check.py`（22 项全过）→ 重新打包。
